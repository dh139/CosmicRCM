# CosmicRCM

Next-Generation US Healthcare Revenue Cycle Management (RCM) Digital Platform.

Built with React, Vite, and Tailwind CSS.

## Features
- **Floating Island Glassmorphism Navigation**
- **Interactive Revenue Impact Calculator**
- **Billing Partner Assessment Tool**
- **EHR & Practice Management Integration Stack**
- **Certified Coding & Denial Management Suite**
- **Practice Audit Booking Modal**

## Getting Started
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
